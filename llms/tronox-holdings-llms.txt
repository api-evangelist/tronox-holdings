# Tronox Holdings

> Tronox Holdings plc is a vertically integrated producer of titanium dioxide (TiO2) pigment,
> mineral sands (titanium feedstock and zircon) and titanium chemicals, mining and processing on
> three continents. It is a Fortune 1000 chemicals and mining company, not a software vendor.

## Read this first: there is no public API

Tronox publishes **no developer program, no public REST API, no OpenAPI, no GraphQL schema, no
AsyncAPI, no SDK and no agent card**. Do not look for `api.tronox.com` or
`developer.tronox.com` - neither hostname has a DNS record (NXDOMAIN, probed 2026-09-17).
Every commercial relationship (TiO2 and zircon supply, customer service, product data) is
contracted directly with Tronox sales.

Supplier transactions run on the **Coupa Supplier Portal**, a third-party platform: registration,
sourcing events, purchase orders, advance shipment notices and invoices are handled inside Coupa
with Coupa accounts. Tronox documents the process in FAQ form only.

- [Coupa Supplier Portal at Tronox](https://www.tronox.com/supplier/coupa-supplier-portal/)
- [Coupa Supplier Portal FAQ](https://www.tronox.com/supplier/coupa-supplier-portal-faq/)
- [Become a supplier](https://www.tronox.com/supplier/become-a-supplier/)
- [Supplier standards](https://www.tronox.com/supplier/supplier-standards/)

## The one machine surface on a Tronox host

www.tronox.com runs the WordPress MCP Adapter. It is the corporate site's content surface,
platform-authored and gated to WordPress users - not an interface to any Tronox business system.

- MCP endpoint (POST JSON-RPC): https://www.tronox.com/wp-json/mcp/mcp-oauth-server -
  anonymous `tools/list` returns `401 mcp_unauthorized`.
- [OAuth authorization-server metadata (RFC 8414)](https://www.tronox.com/.well-known/oauth-authorization-server/)
  - authorization_code + refresh_token, PKCE S256, single scope `mcp`, public client
  (`token_endpoint_auth_methods_supported: none`, client-id metadata documents supported).
- [OAuth protected-resource metadata (RFC 9728)](https://www.tronox.com/.well-known/oauth-protected-resource/)
- WordPress REST index: https://www.tronox.com/wp-json/ (namespaces include `mcp`,
  `wp-abilities/v1`, `wp/v2`, `oembed/1.0`).
